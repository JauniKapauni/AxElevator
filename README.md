# AxElevator
>Minecraft plugin to create elevators
---
## Features
- Build elevator
---
## Installation
1. Download the latest release
2. Put the `.jar` into your `/plugins` folder
3. Start the server
4. Edit config.yml
5. Restart
---
## Configuration
```yaml
# config.yml
elevator:
  block: DIAMOND_BLOCK
  max_distance: 5
```
